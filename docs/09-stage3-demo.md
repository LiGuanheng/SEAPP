# 现场演示与阶段 3 验收

当前展示“亲自探索 → 回营 → 建设阵地 → 指挥士兵 → 布防完成”。建议讲解总用时约 1–2 分钟，默认游戏计时最多 90 + 30 秒；两段均可提前结束，暂停不计时。尸潮与夜战尚未开发，不将布防摘要当作胜利。

## 启动

```bash
npm ci
npm run build
npm run preview -- --port 5173 --strictPort
```

打开 http://127.0.0.1:5173/，桌面键鼠。资源随项目本地加载，保持预览服务运行。开发模式可用 npm run dev。仅想检查已有阵地可打开 /?mode=base；空营地没有免费资源，应先探索。

## 建议演示路线

| 步骤 | 操作与结果 |
| --- | --- |
| 1 | WASD 到工具箱旁 E，得到建材 8、电力 2；可顺路拿步枪并演示射击 |
| 2 | 找工程师林岚 E，观察其跟随；回暖黄色信标等待汇合后 E |
| 3 | 摘要有建材 12、电力 2、工程师；Enter 进入基地，看到 3 名守卫和中央灯塔 |
| 4 | 按 2，在灯塔右上方虚线区左键放机枪塔（例如世界坐标 960,352），工程师折后消耗建材 5、电力 2 |
| 5 | 按 1，在附近放路障，R 可旋转，Esc 取消；观察真实占地、红绿预览与库存变化 |
| 6 | 左键士兵，Shift 加选或拖框；右键让队伍移动到灯塔侧面，看队形、选择圈和目的地线 |
| 7 | G 立即驻守；Space 全选；WASD 平移镜头，滚轮缩放，HUD 不跟着缩放 |
| 8 | Enter 提前完成布防，或等 30 秒自动完成；摘要显示设施、部队和剩余库存 |
| 9 | 点击继续调整，阵地与余额保留；刷新后通过 /?mode=base 确认部署和库存仍在 |

## 验收重点

1. 不能把设施建在十字通道、士兵脚下、部队目的地或已有设施上；失败不扣费。
2. 用路障围住士兵时，封口那座应拒绝，避免卡死。
3. 同一设施 Delete 一次即可回收，第二次不能重复返材料；返实际支付建材的一半向下取整，不返电力。
4. 右键移动必须实际绕过设施、每人有独立落点；G 取消移动。
5. P 暂停、切窗口自动暂停，计时和单位停止，恢复后镜头不会继续漂移。
6. 营救教官后基地增至 4 人；工程师减少建设成本。已有名单不会重复生成同 ID 士兵。
7. 库存和阵地同存档保存；读坏档不立即覆盖，写被禁用时仍能操作并显示未保存。

保存时机为建造、拆除、下令、完成、返回探索，不逐帧保存行军位置；刷新会从最近保存的位置/指令继续。当前没有基地进攻敌人、自动攻击、夜间光照、音效和完整昼夜胜负。人工仍需判断镜头速度、画面比例、操作手感和现场电脑帧率。
