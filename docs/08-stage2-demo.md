# 现场演示与阶段 2 验收

当前可展示“探索 → 搜刮 → 找武器 → 救人 → 护送回营 → 资源入库”。探索默认最多 90 秒，可提前返营。建设和夜战尚未接入；后续完整昼夜计划约 4 分钟。

## 展示前

```bash
npm ci
npm run build
npm run preview -- --port 5173 --strictPort
```

打开 http://127.0.0.1:5173/，点击画面，使用桌面键鼠。提前加载本地资源；演示时无需联网下载素材，保持本地服务运行。不要直接双击 dist/index.html。

顶部为目标和倒计时，地面暖黄光圈引导。WASD 移动，Shift 冲刺，鼠标瞄准/左键射击，R 换弹，Esc 暂停。失焦后会暂停，回来主动按 Esc/P 继续。

## 建议 30–60 秒演示路线

| 顺序 | 操作 | 可见结果 |
| --- | --- | --- |
| 1 | 向右靠近第一个补给箱，E | 建材 +8、电力 +2，箱子变为已搜刮，负重增加 |
| 2 | 继续向右下靠近暖色武器箱，E | 获得 AR 步枪并装备；1/2 可切枪 |
| 3 | 鼠标瞄准丧尸，左键射击，再 R | 枪焰、弹道、受击/死亡，弹匣与换弹受规则限制 |
| 4 | 向左下找到工程师林岚，靠近 E，再走开 | 提示加入队伍，NPC 实际跟随 |
| 5 | Tab 查看背包，再 Esc 关闭 | 本轮物资、装备、随队人员和营地库存；打开期间时间停止 |
| 6 | 回到出生点左下暖黄信标圈内，等队员跟上，E | 立即结算，工程师和物资回营，工程师额外 +4 建材 |
| 7 | 刷新，再 Tab | 累计营地库存仍在，新背包归零，验证持久化 |

想展示自动结束时，不要主动返营；持续战斗生存到 90 秒自动“黄昏收队”。死亡可 Enter 重试，失败不带回本轮物资。讲解停顿用 Esc，倒计时不包含暂停。

## 补充验收

1. 同一箱连续 E 不能重复领物资；超重时保留箱子。
2. 医疗箱提供急救包，受伤后 H 恢复最多 50 生命，满血不消耗。
3. 西北侧陈安是医护员，营救时治疗 20；东侧周野是教官，随队换弹耗时减少 20%。
4. 工程师掉队时提前回营会提示等待；自动收队只带回主角附近已汇合队员。
5. 连续切枪不能补满弹匣；在途子弹保留原枪伤害。
6. 移动/开火时切窗口再回来，应暂停且无残留输入。调整窗口后仍正确瞄准。

限制：NPC 不受伤/不开火，备用弹药无限，无中途存档。探索途中刷新会丢失本轮未入库资源。当前物资预留给下一阶段基地建设，没有可操作的建设或夜战。
