# 尸群微调与行进方向修复（2026-11-01）

## 难度

三档只提高数量系数，保留上一轮的生命、伤害、移速和技能参数，以及困难前两夜的逐步提升。

| 难度 | 原数量系数 | 新数量系数 |
| --- | --- | --- |
| 简单 | 0.75 | 0.76 |
| 普通 | 1.00 | 1.01 |
| 困难 | 1.25 | 1.26 |

困难夜战的数量插值以普通数量系数为基准，前两夜也只获得约一个百分点的微调，不会把全部困难倍率提前到第一关。波次按整数刷新，因此不是每波都多一只。固定种子3的五阶段普通总出兵为120、201、316、409、481，调整前为120、200、314、404、474；困难为130、234、394、505、591，调整前为128、233、394、502、586。

## 行进与动画

- 保留可复现的八方向流场与不穿墙角规则。等步数的相邻格先比较实际行进距离，再比较接近目标的程度，减少由遍历顺序产生的过早斜走。
- 畅通时继续直接追踪目标；绕障和目标本就在斜向时仍允许自然的斜向移动。
- 探索与夜战都按碰撞后的真实位移更新朝向；完全受阻时停止行走动画，避免朝斜向看、实际沿墙直移的侧滑感。击退期间保留受击朝向，接战时朝向攻击目标。
- 完全没有可通行格的地图安全返回不可达状态。

## 验证

`tests/navigation.test.ts` 覆盖等价路线选择、长墙绕行、不可达区域、探索/夜战碰撞滑动和小幅数量变化。`npm test` 共136项通过。

`scripts/validate-balance.mjs` 保持同一组物资、建筑与守军，验证三档各三个布置变化的五阶段战役。后两夜的参考策略会保留一发炮火支援处理末轮或核心告急，优先支援靠近灯塔的敌人，仍只消耗游戏提供的两发支援；不增加单位、不修改血量或库存。另验证普通不使用支援及困难单侧堆叠阵型。固定条件模拟不代表人工通关率。

浏览器专项检查探索追击、进出房屋、真实布防、普通第二/第五夜、困难第二夜以及通关成绩界面。提交和发布在 `main` 上进行。

本轮结果：136项模型测试、9项API测试、9项浏览器专项均通过，前后端构建通过。三档各三个固定条件战役均完成五阶段；普通另有一组不用炮火支援的战役通关，困难单侧堆叠仍会失守。模型结果不写入线上排行榜。
