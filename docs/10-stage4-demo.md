# 完整昼夜演示与阶段 4 验收

默认流程：白天探索 → 回营摘要 → Enter 进入布防 → 30 秒或 Enter 自动入夜 → 守住 120 秒 → 黎明胜利；灯塔耐久归零则提前失守。最多 90+30+120 秒模拟时间，约 4 分钟；暂停、摘要阅读和讲解另留余量。前两段提前结束时通常约 2–3 分钟。

## 启动

```bash
npm ci
npm run build
npm run preview -- --port 5173 --strictPort
```

打开 http://127.0.0.1:5173/。开发启动可用 npm run dev。正式展示先用生产预览加载好本地素材，保持服务运行。当前没有发布线上地址。

| 阶段 | 操作 | 展示点 |

| 探索 | 工具箱 E，武器箱 E，工程师林岚 E，再回暖黄信标 E | 实际移动、射击、搜刮、拾枪、护送；带回建材 12 / 电力 2 与工程师 |
| 入营 | 回营摘要 Enter | 切换俯视基地，继承实际物资 |
| 建设 | 2，在灯塔右上方放机枪塔，例如世界坐标 (832,352)；1 在右下方放路障，例如 (960,640)；R 可旋转 | 工程师折后塔花 5 建材/2 电力，路障 2 建材；有红绿预览与占地校验 |
| 部署 | 左键或框选士兵，右键移动，G 驻守，Space 全选；可留至少一人守南侧 | 独立队形、绕障、镜头移动/缩放 |
| 入夜 | 等 30 秒或 Enter 提前结束布防 | 自动开始夜战，夜战中不能建造/拆除 |
| 守夜 | 自动射击；继续框选/右键调动。F 后左键敌人聚集处呼叫炮火 | 三类敌人、五波进攻、弹道/命中、设施受损、爆炸、有限支援 |
| 视听 | 任意键鼠操作解锁声音，M 可静音；观察灯束与软视野 | 运行时原创枪声/爆炸/环境低鸣，没有额外素材下载 |
| 结束 | 灯塔存活至 120 秒 | 黎明胜利，显示击杀、灯塔耐久、生还守卫、留存设施与支援次数 |

普通感染者慢，疾行者快而脆，重装者耐久高、伤害高。第 3/25/50/76/100 秒开始五波，共计划 81 只；末段更密集。最多同时在场 48 只，不会无限堆积。

每夜 1 次营地支援，获得步枪后为 2 次；8 秒冷却，只能打己方视野内区域，0.65 秒后造成半径 98 的范围爆炸，不伤己方。建议把至少一次留给重装或密集尸群。医护员名单每 8 秒给一名受伤生还守卫治疗 8，不会复活阵亡单位。

## 补充验收

1. 不建塔、不调整防线通常会失守，不是到时间固定播放胜利。
2. 敌人能杀死士兵/摧毁设施，灯塔受击减少耐久并闪红；归零立即失败。
3. P 或失焦暂停，尸潮/单位/弹体/计时停止，点遮罩下面的按钮不能改变指令。回来主动继续，不卡键、不漂移。
4. 灯塔存活到天亮就算守住，即使还有敌人；不能因为某一波清空而提前胜利。
5. 成败后等待、乱按射击或 F 不再改变结果。Enter 用入夜前阵地重试，次数/冷却/敌人重新初始化；胜利次数不因多次点击结算而重复增加。
6. 存储被禁用时仍能结算，明确显示未保存。刷新不会续接夜战中途，而是重新开始；战损只计当前摘要，不永久删除重试阵地。

## 练习入口与边界

- /?mode=combat：原动作训练。
- /?mode=base：布防训练，完成后 Enter 继续调整，N 才进入夜战。
- /?mode=night：直接用现有阵地开始守夜；不会额外送建材或设施。

当前是一昼夜本地可玩版本，未做多日养成、精确墙影、联网和触屏适配，音效只覆盖夜战。炮塔/步枪备用弹药无限，支援和资源有限。主观画面、操作、难度与现场设备帧率仍请实际试玩记录。部署平台和正式任务书待核对；已有生产构建及手动部署工作流，未执行远端发布。
