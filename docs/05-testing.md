当前版本 v0.4（2026-10-23），阶段 3 结果见文末。阶段 1、2 结果与限制保留为历史，不代表当前功能边界。

## 自动化

```bash
npm ci
npm test
npm run build
npm run test:legacy
npm run test:e2e
```

浏览器默认本机 Chrome。无 Chrome 时安装 Chromium 并设置 `PLAYWRIGHT_CHROMIUM=1`。产物测试先构建，PowerShell：`$env:E2E_PRODUCTION='1'; npm run test:e2e`；Linux/macOS：`E2E_PRODUCTION=1 npm run test:e2e`。

浏览器使用真实键鼠操作，配合只读状态验证结果；规则测试验证连续碰撞、枪械、导航、攻击冷却与上限。

## 战斗训练人工试玩步骤（`?mode=combat`）

1. 启动打开网页，确认直接出现实际城市与角色，判断像素风格和比例是否满意。
2. WASD 与斜向移动，贴墙/废车走动，确认无穿透和明显卡住；Shift 冲刺后观察体力。
3. 向四周射击，检查枪口、弹道、命中一致，有闪白/击退/粒子和死亡反馈。
4. 走到远处让镜头跟随，再射击；尝试射墙后敌人，确认挡弹。
5. 打空自动换弹；打一部分按 R，检查换弹进度与弹匣。
6. 让丧尸追上，观察绕障、受伤和死亡，Enter/按钮重试后继续操作。
7. 移动/开火时切换窗口或标签，再回来主动继续，检查不卡键、不自动开火、不受后台伤害。
8. Esc/P 暂停约五秒再继续，确认位置与计时不跳进度。
9. 连续试玩至少五分钟，记录帧率、手感、丧尸卡位和报错。

反馈请含浏览器、窗口尺寸、复现步骤与预期/实际。触屏、其他浏览器、线上部署尚未验证，不宣称兼容。

## 5. 本轮发现与修复

- Node strip-only 测试不支持 TS 参数属性：纯规则层改用显式字段，保证无需 Phaser/浏览器即可测试。
- 射线直通但身体会卡住墙角：导航视线检查加入半径膨胀，绕障测试通过。
- 精灵车体和道路竖线索引错误：依据原图集索引修正，已重新截屏。
- 树干、垃圾桶原本可穿过：地图配置与渲染共享物件定义，加入脚底碰撞，重新执行规则与浏览器验证。
- 持续按住冲刺时体力阈值抖动：先用失败测试确认，加入恢复阈值后通过。
- 感染者可完全重叠：先用失败测试确认，加入有界身体分离和玩家身体间距后通过。

## 6. 阶段 1 限制记录（历史）

本轮没有发现阻塞场景运行的测试失败。当前只有基础感染者、单张练习地图、无限备用弹药，无战斗存档、音频或完整昼夜；这是阶段边界，不标记为完整游戏。

Phaser 全量引擎使入口 JS 约 1.22 MB，gzip 约 329 KB；Vite 提示超过默认 500 KB 分块阈值，但类型检查与构建成功。后续可按实际部署需求拆包，不为此提前扩展玩法。

美术比例、镜头平移、射击手感和实际难度必须等用户试玩。只验证桌面 Chrome；其他浏览器、触屏、线上部署和目标设备长时间帧率尚未验收。共享网格导航与软分离不是大型军团最终方案，阶段 3 再按军队规模设计。

本轮处理了切枪误补弹风险（独立弹匣、取消换弹）、在途子弹伤害随枪变化（发射时固定伤害）、结算重复发奖（模型和存储各一次保护）、掉队 NPC 被远程带回（距离校验与等待提示）、已装备步枪再按 2 却提示未找到（按是否拥有判断）。部分属于实现时预防处理，不伪称已发生线上故障。

最终自动收队截图发现：固定步长浮点累积使 90 秒结算画面被向下取整显示为“89 秒”，顶部仍显示“1s”。已将自动收队时间规范到精确 90 秒，补充严格断言并重跑该 90 秒生产浏览器案例，确认顶部为 0s、摘要为 90 秒。

当前限制：只有探索闭环，无建设/军队/夜战；NPC 暂不受伤/射击；无限备用弹药；无随机地图/物品丢弃/出发配装/中途存档。Chrome 桌面已验证，其他浏览器、触屏、线上部署与展示电脑帧率待人工验收。入口 JS 约 1.24 MB（gzip 334 KB），仍有大于 500 KB 的分块提示，不影响构建成功。
