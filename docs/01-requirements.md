# 需求分析 · 实时重构 v0.4

更新日期：2026-10-23。阶段 0–2 已实现；用户明确要求代提交并开始下一阶段，本轮推进阶段 3。画面、手感与难度仍待用户试玩。

## 1. 目标与范围

最终目标为单机 2D 末日生存 + RTS 塔防：白天亲自探索、搜刮和救援；黄昏建设设施与部署军队；夜晚指挥防守。首个完整版本仅做一个昼夜，不沿用旧版五夜结构。

当前实现动作战斗、探索返营、基地建设、士兵选择与指挥。最终目标不等同于已实现功能。主要用户为桌面键鼠玩家、课程评阅者和维护开发者；触屏不属本轮验收。

## 3. 非功能需求

| ID | 要求 | 验证 |
| --- | --- | --- |
| N-01 | 主体在 Phaser，HTML 仅容器与载入失败提示 | 页面与代码 |
| N-02 | 战斗模型独立于 DOM/Phaser，固定步长 | Node 规则测试 |
| N-03 | 生产资源相对路径，无 CDN，支持子路径部署 | 构建与生产预览 |
| N-04 | 素材加载失败给出可读错误，不静默黑屏 | 模拟资源失败 |
| N-05 | 窗口缩放后瞄准仍正确 | 浏览器键鼠验证 |
| N-06 | 不覆盖旧存档，不伪造提交或协作 | 源码与文档 |

## 4. 排除与待判断

本轮不实现完整夜战、尸潮、灯塔受击、动态夜间光照、迷雾、爆炸、音频和复杂对话。基地暂无敌人，士兵/炮塔不自动攻击；探索与布防结算不代表守夜胜利。探索 NPC 暂不受攻击；无出发配装、物品丢弃、随机地图或探索中途存档。

为现场验收，后续完整昼夜规划为探索 90 秒 + 建设 30 秒 + 夜战 120 秒，总计约 4 分钟，可提前结束探索。此时长为 AI 根据用户“不要太长”的要求提出，尚待试玩确认。

美术比例、速度、射击节奏、镜头和难度为 AI 提议，等待用户试玩判断。正式任务书、文档模板和部署平台仍待核对。
