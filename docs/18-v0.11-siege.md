# v0.11 第一批：末日围城与连续场景演出

接手基线：2026-10-26，本地分支 `codex/story-lantern-and-fog`，HEAD `3278b6b88a92820a58ce2e7e86dfc9d5231fd1c3`，版本0.10.1，工作树干净。未使用远端覆盖本地。

## 诊断与证据

基线 `src/config/night.ts` 已有72敌人上限、3/4/5只批次、100/162/230名计划兵力，不是更早的旧刷怪实现。本机重跑 `simulate-progression`，三阶段峰值20/33/55，灯塔380/380/324；前两阶段防线几乎没有危机。

基线 `NightWorld.step` 把每名敌人用 `(i + wave + column) % 4` 轮转分给入口，同批兵力分散；入口仅±24偏移，形成稀疏长队。最后一波94秒才出发，第三阶段东入口距灯塔1152像素，慢速重装在26秒剩余时间内很难接近核心。胜利判定原本就是120秒存活，无需清场，并非误判提前胜利。`NightView.update` 对 `!canSee` 的精灵完全隐藏，外围再多的真实敌人也看不到。

基线 `target`、每敌建筑查找均分配数组并排序；单位分离遍历所有敌人对。敌人流场把所有可摧毁设施当永久障碍，封闭区域可能没有流场方向；半径较大的重型单位也会在狭缝停留。

基线 `SceneTransition` 只有0.7秒衰减的78%全屏深色矩形、上下黑条与30px文字上移，没有世界灯光、真实空间镜头、环境声阶段、Boss/黎明/失守的连续演出；结算HUD立即遮住战场。白天随机布局明确注释“主干道路、门口和教学路线不变”，最多4个32px障碍±8px偏移、物资点与色调变化。九种已有设施已具备功能差异，本轮不重复添加电网/维修/火焰/狙击。

## 第一批实现

- `core/assault.ts`：按阶段的威胁预算、密度、方向数、特殊单位比例；成团前锋、集群、侧袭、重型突破、围城。首夜使用稳定教学计划，后两阶段由营地出发次数生成可复现侧翼。普通/困难用URL `difficulty=hard` 选择，不修改旧档格式。
- 波次提前为3/22/42/64/84秒（最终阶段末轮82秒），提高兵力集中度，不提高已有敌种基础生命与伤害。每个入口有两条错位接敌线；容量紧张时优先Boss并平衡各方向待出兵力，失败出生点会重试，不丢队列。真实实体上限96、弹体160、粒子200、尸体40、区域8。
- `core/spatial.ts`：分桶目标、弹道候选与邻居分离；静态地形的攻城流场为重装/受阻单位提供破墙方向，设施损毁后重建导航。相邻窄缺口需要重装继续扩大，不穿墙。
- `NightView`：外围显示真实敌人的低对比轮廓；暖灯束、受损裂纹、烟迹、破墙碎石；缓慢入夜、黎明散雾和灯塔熄灭。雾层光照使用缓存径向贴图，密集设施按128px单元合并光源；视野规则不受光源合并影响。
- `SceneTransition`：沿现有地图摄像机、灯束、警报灯、雾流、灰烬制作出发/回营/入夜/Boss/黎明/失守，1.25–2.7秒；主要文字缩至角落。Boss演出不暂停模拟、不强制移动镜头。终局先展示真实战损，再显示结算。
- `SoundBus`：原创合成低频升降、警报与群体脚步/嘶吼层，声音受8声部上限和频率限制。Space跳过；V减少动态，按系统减少动态偏好初始化并持久保存。暂停/指南/失焦冻结演出、模拟及音频；倍速仅影响固定步长。滚轮、移动、施工、小地图可随时接管镜头。

没有新增外部美术或音频，新增雾、碎石、灯束、警报、音色均为项目代码原创；原素材来源/许可见07-assets。未更换引擎、三阶段框架、48负重、存档键、重试检查点或建筑数量规则。

`simulate-progression` 按真实成本逐步建设并使用士兵移动命令。第三阶段增加一次24建材搜刮，重炮手北侧、医师核心，才能守到黎明；没有在战斗中增加生命或资源。最终灯塔193、损失设施和部队，证明旧站位不能照搬。合成96敌人满载另测，不冒充自然刷怪截图。

浏览器验证日志与实机截图在 `artifacts/v011*`；专项包含三倍速演出时长、暂停/失焦、跳过、减少动态持久化、四向实际活敌人、Boss、黎明及失败重试。完整37项回归首次35通过、2项Chrome超时，随后单独重跑2/2通过，最终37种案例均通过。不能把首次全量运行写成37/37一次通过。

无并行E2E争用的最终生产Chrome、1280×720、3倍速、8秒真实rAF采样：120设施场景平均8.41ms、p95 18.10ms、最高30.30ms；四面围城平均7.52ms、p95 12.20ms、最高24.20ms，采样峰值77名、4方向、200粒子，JS堆39.46MB，页面错误0。完整模型峰值85与浏览器8秒采样峰值不混用。WebM是浏览器canvas真实捕获、无虚拟时钟、无音轨；不宣称人工录屏或听感验收。

## 试玩

`npm run dev` 后默认探索→工具箱/步枪/急救箱→工程师→信标回营，建设机枪塔、两箭塔和沙袋；注意首夜末段也会产生战损。第二阶段应在西侧补范围火力，第三阶段将兵力分到核心四侧，重炮手照顾北线，外围墙挡集群，电网延缓突破，对空火力留给腐鸦。先用1倍速体验演出，T可提速，P暂停，F支援，V减少动态。`?mode=night` 使用自己的存档阵地，`?mode=base` 可继续调整。不要用压力夹具覆盖自己的存档。

仍需人工判断实际音量、镜头和紧张感；自动化不等于玩家满意度。仅验证桌面Chrome，未宣称低配/移动端/其他浏览器性能。入口Phaser包约1.35MB，仍有Vite大包提示。第3阶段可能需要额外搜刮与重排阵地；“一次探索、不指挥即可稳定过关”不再作为难度目标。
