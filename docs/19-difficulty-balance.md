# 三档难度与五阶段平衡调整（2026-11-01）

旧困难同时增加生命50%、数量55%、伤害25%与速度12%，又叠加提前进攻、重甲掩护、毒池压制和最后30秒狂暴。第二阶段已连续出现重甲，容易形成守军阵亡、火力不足、敌人积压的连锁失守。旧验证的第五关极限库存阵地不能代表前两关的真实资源条件。

## 调整

| 项目 | 当前规则 |
| --- | --- |
| 简单 | 生命与数量为普通的75%，伤害85%，移速95%；Boss技能伤害也遵守难度倍率 |
| 普通 | 保留标准基础属性；减缓阶段属性增长，减少第二关起的兵力密度与单批数量，保留所有Boss与五阶段解锁 |
| 困难 | 白天生命120%、数量125%；夜晚第一关生命105%/数量约106%，第二关112%/约115%，第三关起120%/约125%；伤害、移速也逐步提升 |
| 重甲引入 | 第二关仅末轮一只，第三关末两轮逐步加入；基础生命900→760、护甲45%→40%，仍明显比普通敌人耐打 |
| 困难特殊机制 | 第三关起启用；掩护减直射25%→15%、作用半径145→110；震击蓄力1.4→1.8秒、冷却10→14秒；毒池压制30%→15% |
| 困难末段 | 第三关起最后20秒移速+15%、普攻伤害+5%；前两关不启用 |

波次、出生方向和Boss仍确定性生成；不采用隐藏的自动胜利、临时改血或根据玩家成绩动态放水。守夜仍为120秒；探索、布防和守夜计时及评分公式保持原规则。

## 可复现验证

`node --experimental-strip-types scripts/validate-balance.mjs`

每关按真实价格建设，使用合法位置和默认守军站位，每关最多新增4～5座混合设施。普通和简单每阶段物资依次为16/2、38/12、56/18、78/26、104/34（建材/电力）；困难首关额外收集至28/8，并多建一座机枪塔和加农炮。每阶段物资均在对应单趟背包容量内。后续阶段沿用真实守夜结算的检查点、成长与奖励，英雄按阶段加入，不凭空提供极限库存。

- 每档3种布局/进攻种子变化，共9组五阶段模型均能完成战役。
- 普通另有一组不使用炮火支援的五阶段模型通关；并非要求每次都精确使用支援才能推进。
- 困难同资源的单侧堆叠阵地仍会失守，保留火力覆盖与建筑搭配的作用。
- 模型报告写入忽略目录 `artifacts/balance-report.json`，不提交成绩到线上排行榜。
- 浏览器专项：`npx playwright test tests/browser/balance.spec.ts`，检验普通第二/第五夜与困难第二夜的实际运行及结算。

这些是固定条件下的模拟与浏览器验证，不代表人工玩家通关率。普通模式的参考布防：火力分布在灯塔周围，第二关增加加农炮、后排防空与维修；后续逐关加入新设施，避免把所有武器都改为只能对空。
