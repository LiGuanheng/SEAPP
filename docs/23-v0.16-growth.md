# v0.16 五阶段成长与手动布防

本轮按新的玩法要求修改普通搜救的刷新规则；箱子仍保留搜刮状态，英雄仍是唯一人物。地图、装备与资源继续随阶段成长。版本0.16.0，评分版本5。

普通工程师、医护、教官、弓手、先锋、电工每次出发有新的一批，以不同搜救队编号显示，并更换房屋位置。英雄第2至5阶段各开放一人，已救英雄不再生成。首次工程师教学路线保留；已搜箱子不重生，超重整箱不领取、不销毁。

成功返营的普通人员按照步枪、弓手、先锋三类补入预备队，基地按上限接纳；满员时余下人员作为预备队显示，不覆盖英雄。工程/医疗等职业能力不无限叠加。英雄生命、攻击、治疗乘以`1 + (阶段−1)×0.25`，第5阶段为基础的2倍，名牌显示等级，治疗不会突破各自生命上限。

人物、资源、灯级仍只在成功回营/黄昏收队后入库。阶段重开会恢复该阶段起点的完整世界、物资、预备队和计时。

## 布防、用时与排行榜

布防取消30秒倒计时，不再自动入夜；正常战役点击“完成布防”或Enter后入夜。练习入口`?mode=base`仍允许检查布防完成后的阵地，并按N测试夜战。

通关主要用时 = 探索推进时间 + **实际活动布防时间** + 守夜推进时间。布防计时不受倍速影响，倍速仍能加快部队移动；暂停、背包、指南、排行榜、失焦和离线等待不计入。五夜守夜仍固定累计600秒；布防可短可长，不补足30秒，也不把超过30秒截掉。额外布防增加总用时，同时降低综合得分里的效率奖励。两种排行榜和三档难度继续独立。

后端共用同一评分函数，005迁移开放新版实际布防时长，保留旧版本约束与成绩、旧迁移校验和。当前匿名排行榜不是服务器权威防作弊。按之前约定，先发布静态游戏，线上API和数据库仍稍后配置。

## 实现与验收入口

`growth.ts`统一容量、资源、编制和英雄倍率；`base-migration.ts`迁移阵地；`expedition.ts`生成新人员与结算预备队；`night-world.ts`实现真实伤害、灼光锁定与远程炮弹；`ranking.ts`记录实际布防时间。新增`v016-growth.test.ts`和`growth-v016.spec.ts`覆盖这些规则。

`npm run simulate:progression`为有限资源参考模型，每阶段一趟资源夹具均低于该关背包上限，再加实际首胜奖励，真实施工扣费并模拟120秒夜战。五夜普通难度均守住；不把模型夹具当作人工从零实玩证据。
