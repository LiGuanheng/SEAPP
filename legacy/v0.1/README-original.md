# 最后一盏灯 · The Last Light

软件工程课程项目。一个可部署的单人网页生存策略游戏：白天探索废墟、营救幸存者、寻找武器，黄昏建设设施与部署小队，夜晚守护灯塔抵抗尸潮，在五个昼夜中平衡灯光、能源与火力。

## 本地运行

需要 Node.js 24 或更新版本。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。构建与验证：

```bash
npm test
npm run build
npm run test:e2e
```

浏览器测试默认使用本机 Chrome；没有 Chrome 时，先执行 `npx playwright install chromium`，再以 `PLAYWRIGHT_CHROMIUM=1` 环境变量运行。详细说明见 [测试说明](docs/04-testing.md)。

## 操作

1. 每个白天选择一处地点探索，获得补给、特殊武器或救援人物；首次探索保证救回工程师和找到燃烧瓶。探索不是开战的强制条件。
2. 点击防御设施卡，再点击地图中的 `＋` 建造点部署。也可用地图下方的建造点按钮完成键盘操作。
3. 调节灯光；亮度越高，射程和探索收益越高，但夜间耗能与敌人数也更多。
4. 可花 45 材料将三人守备小队部署到防区。点击“迎接黑夜”，设施与小队自动攻击；必要时消耗能源释放“灯塔脉冲”，或使用燃烧瓶、震荡弹。
5. 守过夜晚后选择一项强化，进入下一天。守过第五夜获胜，灯塔耐久归零失败。

感染者分普通、疾奔与重型三类；工程师、医生和队长分别帮助搜寻材料、修复灯塔与提高小队伤害。支持暂停、1×/2×速度、设置、重新开始和本机自动存档。完整规则见 [需求分析](docs/01-requirements.md)。

## 项目结构

```text
src/game/       独立游戏规则、地图、数据定义与存档校验
src/ui/         Canvas 地图绘制与音效
src/main.ts     页面交互与游戏循环
src/style.css   响应式界面
tests/         规则测试与浏览器端到端测试
docs/          需求、设计、开发记录、测试与部署说明
```

## 发布

`npm run build` 生成 `dist/`，可部署到静态网站托管服务。已提供手动触发的 GitHub Pages 工作流，启用前请阅读 [部署说明](docs/05-deployment.md)，尤其是私有仓库的套餐与站点访问权限说明。

游戏图形使用代码绘制，无外部图片、字体或音乐依赖。
