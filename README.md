# 最后一盏灯 · The Last Light

使用 Phaser + TypeScript 实现的 2D 末日生存探索与即时防御游戏。

**v0.17：困难模式强化与高清画面。** 默认1440p画布，文字、矢量设施、英雄和Boss同步高清载入；菜单可选4K超清或标准720p。困难相对普通生命+50%、计划数量约+55%，进攻更早更密集，新增巨尸掩护、攻城震击、毒池压制与末段狂暴，需要分散交叉火力、防空、群伤和调兵。旧成绩保留，新规则独立分榜。详见 [v0.17设计与验证](docs/24-v0.17-challenge-hd.md)。

**v0.16：五阶段成长与手动布防。** 灯塔位于真正的地图中心，施工区同心扩建；普通人员每趟换位刷新，英雄唯一且逐阶段增强。背包48→72→104→140→184，后期补给更多、预备队补充守军。每阶段开放新建筑，防空火炮（2）、震地锤（3）、重型狙击与灼光塔（4）、苍穹重炮（5）。布防不限时，完成后手动入夜，实际布防耗时计入双榜与效率评分。详见 [v0.16玩法与实现](docs/23-v0.16-growth.md)。

沿用五夜战役、主菜单、三档难度与阶段重开，当前计时以v0.16为准，历史规则见 [v0.14说明](docs/21-v0.14-game.md)。

[开始游戏：GitHub Pages](https://liguanheng.github.io/SEAPP/)。本轮按用户选择先发布游戏，在线排行榜 API 和数据库稍后配置；未连接时会明确提示，单机游玩与结算正常。

后端采用 Node.js 24 + TypeScript + Fastify + pg + PostgreSQL + Zod，不要求账号。服务端重算分数并验证边界，UUID 防意外重复；**客户端数据仍可伪造，不是服务器权威防作弊**。未配置 API 或断网时单机照常运行。

本地后端快速开始（先安装并启动 Docker Desktop；Node API 与容器 API 选一种）：

```powershell
npm ci
npm ci --prefix server
Copy-Item .env.example .env
Copy-Item server/.env.example server/.env
docker compose -f compose.yaml -f compose.dev.yaml up -d db
npm --prefix server run migrate
npm run server:dev
# 另开终端
npm run dev
```

根 `.env` 的 VITE_API_BASE_URL 只填公开 API 来源，不放密码。生产 Pages 工作流读取同名 Actions Variable，只发布 dist。当前线上游戏先使用未配置API的单机模式，后端本机验收替代方案见指南第8节。

## 启动与操作

需要 Node.js 24+。

```bash
npm ci
npm run dev
```

打开终端中的本地地址进入主菜单；开始新战役后首次播放序章，再进入城市探索。同一标签页记住已观看；可用 `/?intro=1` 重播。点击画面获得焦点。推荐桌面键鼠。首片街区建议短路线：工具箱 → 步枪箱 → 右上急救补给箱 → 工程师 → 暖黄色信标按 E；可获得 16 建材 / 2 电力（含工程师返营奖励）。搭配机枪塔、两座箭塔和沙袋形成交叉火力。后续街区布局随机，跟随实际目标指引搜救。

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准与射击 | 鼠标瞄准，按住左键射击 |
| 换弹 | R；空弹匣后自动换弹 |

工程师返营额外回收建材，医护员救援时治疗，教官随队加快换弹。背包按阶段提升至48/72/104/140/184，搜刮整箱放不下时保留原箱。无限备用弹药用于当前演示，枪械仍有弹匣、射速和换弹限制。

持续世界包含六片街区，五阶段依次开放2→6片。首片保留教学补给线，其余街区打乱六栋建筑的分区、尺寸与门位，并重新布置物资和人员；街区内部布局与未搜奖励保持稳定。自动优先前往新开放、未搜尽、较少访问的区域。成功回营保存空箱与救援记录，已救英雄在所有街区消失；普通人员每趟换位刷新，成功护送后可补充部队；后续可空手返营更换街区。南门可进入，屋顶会隐藏，墙体和家具真实阻挡移动、弹体及灯光。可选危险货仓/感染救护点/受困车队仍有伏击；守军编制按阶段最多6/8/10/12/12人，英雄优先占编制。探索中途刷新或失败丢失本轮尚未带回的发现。

消防斧朝鼠标方向扇形横扫，48 伤害、70 像素距离、0.6 秒间隔，不耗弹药，不能隔墙命中；猎弓为慢射速、高单发伤害的真实箭体，切换后需等待攻击冷却。白天随队人物暂不受伤，先锋需要靠近敌人才能发挥作用。

到 90 秒自动黄昏收队；提前回营需到信标附近按 E，等队员跟上。只有结束时距主角 150 像素内的已汇合队员计入营救。失败不会带回本轮物资。回营后写入独立 `last-light.campaign.v2` 营地存档，刷新可查看累计库存；探索中途刷新会丢失本轮进度，旧 `last-light.save.v1` 不读写。已成功带回的步枪、猎弓在后续探索直接可用。

## 提灯、迷雾与家园

黑雾吞没旧城，北境灯塔为幸存者留下家园。玩家是守灯人：白天带灯寻找补给、武器与幸存者，黄昏建设防线，夜晚守住灯塔直到天亮。序章使用现有像素场景、怪物剪影、旋转灯束和幸存者动画，不要求阅读长对话。

探索初始照明半径 240 像素，墙体遮挡光线。未探索区被黑雾遮住，离开后仅保留暗色地形；敌人与人物只在当前视线中显示，小地图不再提前泄露全部补给和人物。任务方向与回营信标仍作为已知情报显示。

街边 (1152,688) 的金色箱提供聚光镜片，将半径升到 320；药房室内 (1024,432) 的箱子同时提供猎弓和高能灯芯，将半径升到 400。镜片不占负重，不能重复强化或把高级灯降级。灯光升级即时生效，但只有安全返营/成功黄昏收队才入库；失败丢失本轮新升级，已带回的灯级下次出发自动使用。

出发、归来、进入基地、入夜、Boss、黎明和失守使用1.25–2.7秒真实场景镜头、雾流、灯束与音色演出；演出不消耗额外阶段预算，不随倍速加快。Space跳过，V减少动态，镜头操作随时接管；暂停/指南/失焦冻结表现与模拟。

## 夜战

七类普通敌人与六种Boss按阶段编成，前锋、集群、侧袭、突破、全面围城分段出动；包含高血量、减伤护甲的铁甲巨尸。后期四向同时推进，末轮提前出场，让重装有时间接近。真实实体最多96、弹体160、粒子200；未出兵力排队，外围轮廓来自实际敌人。三档难度调整敌人生命和数量。持续至120秒且灯塔存活即胜利，同一步归零优先判负。

| Boss | 特性与应对 |
| --- | --- |
| 裂颅巨汉 | 重斧范围攻击，0.95 秒预警，调兵离开圈内 |
| 蜘蛛女皇 | 蛛网持续伤害并减速，召唤快速蜘蛛幼体 |
| 亡灵骑士 | 25% 护甲减伤，召唤有轻甲的亡灵侍从，集中火力 |
| 腐羽巨鸟 | 飞越墙体，腐羽风暴持续伤害；机枪、箭塔、狙击和枪/弓守卫能对空 |
| 蚀雾喷吐者 | 360射程锁定毒池，1.1秒预警，持续5秒；调兵离开落点 |
| 熔囊巨怪 | 靠近后1.6秒蓄力、125范围自爆；可用集中火力击杀打断，自爆不计玩家击杀 |

近战先锋与加农炮仅攻击地面目标，城墙不能拦住飞行单位。顶部显示 Boss 血条和技能说明，地面出现落点预警；小地图金色为 Boss、紫色为普通飞行敌人。基地世界2048×1408，灯塔位于地图中心，可建设范围从1408×832同心扩至全图，缩放最低0.5倍；战术地图显示本阶段施工边界，旧阵地会自动迁移。

| F，再左键落点 | 有限炮火支援，0.65 秒后范围爆炸，不伤己方；右键/Esc 取消 |
| M / 声音按钮 | 白天和夜战音效开关，首次键鼠操作后解锁；静音偏好保留 |
| P / Esc / 暂停按钮 | 暂停尸潮、部队、计时和音效；失焦自动暂停 |
| 终局 Enter | 前四夜胜利进入下一阶段布防；第五夜胜利或死亡查看最终成绩 |

每夜自带 1 次营地支援，白天取得步枪后为 2 次，冷却 8 秒，只能打己方视野内落点。医护员名单每 8 秒给一名受伤生还守卫恢复 8 生命。备用弹药仍无限；夜间禁止施工/拆除。具备动态视野迷雾、暖色灯束、弹道/命中/爆炸、限量尸体、黎明与胜负画面、原创合成音效。白天为柔和钟琴/和弦循环，夜战增加低音节奏；L 单独控制配乐，M 控制全部声音。

倍速通过更多固定步长推进整个模拟：移动、子弹、攻击冷却、波次、支援、治疗与截止时间同步加速。镜头移动、UI 和配乐保持正常时间，避免操作突然过快或音乐升调。

战术地图显示己方守卫、设施和当前视野内敌人，白框表示镜头范围。顶栏预告下一波时间与类型，尸潮开始时提示。F1 指南提供本阶段操作和演示建议，覆盖时不会触发下面的战斗/施工按钮；从背包或暂停状态进入指南，关闭后仍保持原状态。失焦后需主动恢复。

入夜前阵地作为营地检查点；战后保存摘要、成功次数、通关阶段和一次性补给，下一次布防恢复原设施与守卫，界面明确提示免费修复。死亡终止当前成绩会话，点击“开始新战役”重新开始。夜战中途刷新只能恢复营地检查点，不支持断点续战，刷新也不继承本局排名计时。首次胜利补给按阶段记录，不能重复领取。

练习入口：`/?mode=combat` 为原战斗训练；`/?mode=base` 为布防训练，完成后 Enter 继续调整、N 开始夜战；`/?mode=night` 直接使用已有阵地守夜，没有免费设施。默认入口为完整流程。
